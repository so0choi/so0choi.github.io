회사에서 VOD 영상의 얼굴 인식 기능을 개발하게 되어 해당 기능에 대해 파보던 중 이 기술의 근본이 되는 머신 러닝에 대해 공부하게 되었다. 대충 들어는 봤지만 명확히 뭐라고 설명할 수 없었던 개념에 대해 알아보려고 한다.

## 머신러닝이란

ML이라고 흔히 말하는 머신러닝은 데이터에서 패턴을 학습한 모델이다. 학습을 통해 다음 데이터를 예측을 하거나 데이터로부터 콘텐츠를 생성하는 프로세스를 뜻한다. 예를 들어 강수량을 예측하는 앱을 만든다면 ML 없이 기존 방식으로는 아주 복잡한 방정식을 구해 예측값을 구한다. 반면에 ML은 여태까지 수집된 엄청난 날씨 데이터를 모델에 학습시켜 현재 날씨 데이터를 제공했을 때 강우량을 예측하도록 하는 것이다.

![AI-ML-DL.svg](../../../../../../../Downloads/AI-ML-DL.svg)

머신 러닝은 AI의 하위 집합이며 그 내부에는 딥러닝이 있다.

- AI: 기계가 인간의 지능적 작업을 수행할 수 있도록 하는 기술 전반
- ML: 데이터를 학습해 패턴을 발견하고 예측하거나 판단하는 기술
- DL: 여러 층으로 구성된 인공신경망을 활용하는 ML 하위 기술

## 머신러닝의 발전과 지도 학습 방식

AI 연구 초기부터 ML은 등장했다. 초기에는 사람이 정의한 논리와 규칙을 구현하는데 집중했고 이후에는 데이터로 패턴과 규칙을 학습해 실제 문제를 해결하는 도구로 발전했다.

ML 시스템이 콘텐츠를 생성허간 결과를 예측하는 방식은 다음 중 하나 이상에 속한다.

- 지도 학습
- 비지도 학습
- 강화 학습
- 생성형 AI

## 지도 학습

정답이 있는 문제에 대한 데이터를 아주 많이 학습해 정답과 정답을 생성하는 데이터 간 연결을 발견해 예측하는 방식. 학생이 이전 시험 데이터를 바탕으로 새 시험을 준비하는 것과 같다. ML 시스템의 학습 데이터가 올바른 결과여야 한다. 지도 학습의 가장 일반적인 방식으로 '회귀'와 '분류'가 있다.

- 회귀 : 숫자 값을 예측하는 모델이다. 강수량 예측이나 향후 주택 가격, 목적지 도착 예정 시간 등 숫자를 예측하는 사례를 말한다.
- 분류 : 항목이 카테고리에 속할 가능성을 예측한다. 사진에 사람 얼굴이 있는지, 입력받은 이메일이 스팸인지 아닌지 등을 예측하는 데 사용된다. 분류 모델은 또 다시 다중 클래스 분류와 이진 분류로 나눠진다. 이름 그대로 이진 분류는 두 개 분류 중 하나, `비가 온다/비가 안온다` 둘 중 하나로 분류하는 것이고, 다중 분류는 `비, 맑음, 눈` 처럼 여러 분류 중 하나로 출력하는 것을 말한다.

## 비지도 학습

비지도 학습은 데이터 셋에서 패턴을 식별하는 것을 목표로 하는 방식이다. 보편적으로 사용되는 기법은 `클러스터링`으로, 유사한 데이터를 클러스터링이라는 그룹으로 정리한다. 지도 학습의 분류와 다른 점은, 카테고리가 사용자에 의해 정의되지 않고 모델이 스스로 패턴을 식별한다는 점이다.

## 강화 학습

강화 학습은 모델이 수행한 작업을 기반으로 보상 또는 불이익을 받아 올바른 동작이 무엇인지 예측하며 모델을 강화시키는 방식이다. 강화 학습 시스템은 더 많은 보상을 얻기 위한 최적의 전략을 정의하는 정책을 생성해낸다. 알파고 같은 소프트웨어 프로그램을 학습시키는 데 사용되는 방식이다.

## 생성형 AI

사용자 입력으로 콘텐츠를 생성하는 모델이다. 고유한 이미지, 음악을 생성할 수 있고 기사를 요약하거나 사진을 수정할 수 있다. 챗 GPT나 제미나이 등이 여기 속한다. 생성형 AI는 새로운 유사 데이터를 생성하기 위해 데이터 패턴을 학습한다. 창의적 출력을 생성하기 위해 비지도 접근 방식을 활용해 초기 학습되며 이후 지도 학습이나 강화 학습을 사용해 추가 학습이 가능하다. 새로운 사용 사례가 끊임없이 발견되며 빠르게 발전하는 기술이다.


## 그렇다면 머신러닝과 얼굴 인식 기술은 무슨 관계인가

지도 학습의 분류 방식을 잘 활용하면 이미지에 사람의 얼굴이 존재하는지 판단하는 모델을 만들 수 있다. 다만 영상에서 얼굴을 찾으려면 얼굴의 존재 여부뿐 아니라 이미지 내에서 얼굴이 어디 위치하는지도 알아내야 하는데 이는 얼굴 탐지(face detection) 기술이다.

얼굴 탐지와 얼굴 인식(face recognition) 또한 서로 다른 기술읻. 얼굴 탐지는 얼굴의 위치를 찾는 기술이고, 얼굴 인식은 탐지된 얼굴이 누구의 얼굴인지 식별하거나 두 얼굴이 동일 인물인지 판단하는 기술이다.
